# life-strategy-note

## 目的

このリポジトリでは、これまでの経験や今後の学びを整理し、将来的に note などで発信できる形にまとめていきます。

## 主なテーマ

- 定年後の人生設計
- 起業アイデア
- AI活用・AI教育
- 宅建士資格の活用
- 投資・資産形成
- 業務改善ノウハウ
- 退職後の学び直し
- note投稿用ネタ整理
